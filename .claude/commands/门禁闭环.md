# /门禁闭环

你是总编辑。执行本命令时，必须按固定顺序完成当前章节的完整门禁闭环：

```text
/更新记忆 → /检查一致性 → /节奏审查 → /风格校准 → /校稿 → /门禁检查
```

任一步骤失败，都不得进入下一章。

## 参数

从用户输入 `$ARGUMENTS` 中识别：
- `--project-root <项目目录>`：小说项目根目录。缺失时询问用户。
- `--chapter-file <章节文件>`：当前章节正文。可为绝对路径或相对 project-root。缺失时优先选择 `03_manuscript/` 中最新章节，无法判断时询问用户。
- 其余文本视为本章变化说明，传入 `/更新记忆` 参考。

## 执行步骤

### 0. 准备

1. 读取章节正文。
2. 建立/确认门禁目录：
   - `04_editing/gate_artifacts/<chapter_id>/`
3. 创建或更新 `pipeline_todo.md`：

```markdown
# 章节流程待办

- [ ] /更新记忆
- [ ] /检查一致性
- [ ] /节奏审查
- [ ] /风格校准
- [ ] /校稿
- [ ] /门禁检查
- [ ] /更新剧情索引
```

### 1. /更新记忆

按 `.claude/commands/更新记忆.md` 执行，写入：
- `memory_update.md`

完成后勾选 `pipeline_todo.md` 对应项。

### 2. /检查一致性

按 `.claude/commands/检查一致性.md` 执行，写入：
- `consistency_report.md`

如出现 P0 一致性问题，停止闭环，提示用户执行 `/修复本章`。

### 3. /节奏审查

按 `.claude/commands/节奏审查.md` 执行，写入：
- `pacing_review.md`

如综合结论为“失败”，停止闭环，提示用户执行 `/修复本章`。

### 4. /风格校准

按 `.claude/commands/风格校准.md` 执行，必要时对正文做最小风格修正，写入：
- `style_calibration.md`

### 5. /校稿

按 `.claude/commands/校稿.md` 执行，两遍式去 AI 味润色，写入：
- `copyedit_report.md`
- `publish_ready.md`

### 6. /门禁检查

按 `.claude/commands/门禁检查.md` 执行脚本：

```bash
python3 /home/ubuntu/.claude/skills/novel-creator-skill/scripts/chapter_gate_check.py \
  --project-root <项目目录> \
  --chapter-file <章节文件>
```

读取 `gate_result.json`。

## 成功判定

只有当：

```json
"passed": true
```

才允许进入下一章。否则唯一合法下一步是 `/修复本章` 或回到失败的单步命令补齐产物。

## 输出给用户

简短报告：
- 当前章节
- 六步完成情况
- `gate_result.json` 路径
- `passed` 结果
- 若失败，列出失败项与下一步

## 禁止事项

- 不得跳过任何一步。
- 不得在门禁失败后继续写下一章。
- 不得手动修改 `gate_result.json` 伪造通过。
- 不得把报告、分析、TODO 写入小说正文。
- 不得修改 `novel_plan.md` 主线架构。
