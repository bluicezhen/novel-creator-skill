# /门禁检查

你是发布门禁执行者。执行本命令时，只运行脚本化检查，不补写缺失产物，不手动修改 `gate_result.json`。

## 参数

从用户输入 `$ARGUMENTS` 中识别：
- `--project-root <项目目录>`：小说项目根目录。缺失时询问用户。
- `--chapter-file <章节文件>`：当前章节正文。可为绝对路径或相对 project-root。缺失时优先选择 `03_manuscript/` 中最新章节，无法判断时询问用户。
- `--pacing-tier slow|medium|fast`：可选，传给节奏预演检查。
- `--pacing-event-types <逗号分隔>`：可选，传给节奏配额检查。

## 执行步骤

1. 确认章节正文位于 `<project-root>/03_manuscript/`。
2. 运行：

```bash
python3 /home/ubuntu/.claude/skills/novel-creator-skill/scripts/chapter_gate_check.py \
  --project-root <项目目录> \
  --chapter-file <章节文件> \
  [--pacing-tier slow|medium|fast] \
  [--pacing-event-types <事件类型>]
```

3. 读取 stdout JSON 或产物：
   - `04_editing/gate_artifacts/<chapter_id>/gate_result.json`
4. 向用户报告：
   - `passed`
   - 失败项 `failures`
   - 警告项 `warnings`
   - 下一步：通过则可进入下一章；失败则执行 `/修复本章` 或补齐对应单步命令。

## 通过标准

`gate_result.json` 中 `passed == true` 才算通过。只要 `passed != true`，禁止进入下一章。

## 禁止事项

- 不得手动编辑 `gate_result.json` 伪造通过。
- 不得在失败后继续写下一章。
- 不得把 `/门禁检查` 当成 `/门禁闭环`；缺失产物时应先执行对应单步或 `/门禁闭环`。
