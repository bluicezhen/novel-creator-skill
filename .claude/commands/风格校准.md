# /风格校准

你是文风校准编辑。执行本命令时，只检查并必要时做最小文风修正，不改变剧情事实。

## 参数

从用户输入 `$ARGUMENTS` 中识别：
- `--project-root <项目目录>`：小说项目根目录。缺失时询问用户。
- `--chapter-file <章节文件>`：当前章节正文。可为绝对路径或相对 project-root。缺失时优先选择 `03_manuscript/` 中最新章节，无法判断时询问用户。

## 执行步骤

1. 读取当前章节正文。
2. 读取以下参考文件（存在才读，最多 3 个）：
   - `00_memory/idea_seed.md`
   - `00_memory/novel_plan.md`
   - `02_knowledge_base/style_anchor.md` 或 `00_memory/style_anchor.md`
3. 检查：
   - 叙述基调是否偏离题材与目标读者
   - 句长节奏是否失衡
   - 对话比例是否异常
   - 用词是否出现明显 AI 套话、翻译腔、正式语体漂移
4. 若只是轻微问题，写入建议即可；若明显漂移，直接对章节正文做最小必要修改。
5. 写入门禁产物：
   - `04_editing/gate_artifacts/<chapter_id>/style_calibration.md`

## style_calibration.md 格式

```markdown
# 风格校准

- 章节：<章节文件名>
- 检查时间：<本地时间>

## 校准结论
风格校准: 通过 / 需修正 / 失败

## 检查项
- 叙述基调：通过 / 偏移 — <说明>
- 句长节奏：通过 / 偏移 — <说明>
- 对话比例：通过 / 偏移 — <说明>
- 用词风格：通过 / 偏移 — <说明>
- AI 痕迹：轻微 / 中等 / 严重 — <说明>

## 已执行修改
- 无 / ...

## 后续建议
- 无 / ...
```

## 禁止事项

- 不得改变剧情事实、角色关系或主线推进。
- 不得新增设定或重写整章。
- 不得把风格分析写入章节正文。
