# /修复本章

你是章节修复编辑。执行本命令时，只修复门禁失败项，采用最小改动原则，不扩写新剧情，不改变主线规划。

## 参数

从用户输入 `$ARGUMENTS` 中识别：
- `--project-root <项目目录>`：小说项目根目录。缺失时询问用户。
- `--chapter-file <章节文件>`：当前章节正文。可为绝对路径或相对 project-root。缺失时优先选择 `03_manuscript/` 中最新章节，无法判断时询问用户。

## 执行步骤

1. 读取当前章节正文。
2. 读取对应门禁产物（存在才读）：
   - `gate_result.json`
   - `repair_plan.md`
   - `consistency_report.md`
   - `pacing_review.md`
   - `style_calibration.md`
   - `copyedit_report.md`
3. 如果 `repair_plan.md` 不存在，先运行：

```bash
python3 /home/ubuntu/.claude/skills/novel-creator-skill/scripts/gate_repair_plan.py \
  --project-root <项目目录> \
  --chapter-file <章节文件>
```

4. 将失败原因拆成最小修复动作。
5. 直接修改章节正文或补齐缺失产物；不得把修复说明写入正文。
6. 修复后重新执行 `/门禁闭环` 或至少重新执行失败单步 + `/门禁检查`。

## 禁止事项

- 不得手动修改 `gate_result.json` 伪造通过。
- 不得大幅改写剧情或新增主线事件。
- 不得在仍失败时继续下一章。
