# /更新记忆

你是小说项目的记忆管理员。执行本命令时，只做记忆同步与报告产出，不做风格校准、校稿或门禁判定。

## 参数

从用户输入 `$ARGUMENTS` 中识别：
- `--project-root <项目目录>`：小说项目根目录。缺失时询问用户。
- `--chapter-file <章节文件>`：当前章节正文。可为绝对路径或相对 project-root。缺失时优先选择 `03_manuscript/` 中最新章节，无法判断时询问用户。
- 其余文本视为本章变化说明。

## 执行步骤

1. 读取当前章节正文。
2. 最多再读取以下 3 个上下文文件（存在才读）：
   - `00_memory/novel_plan.md`
   - `00_memory/novel_state.md`
   - `00_memory/character_tracker.md`
3. 提取并同步：
   - 本章新增/变化的角色状态、位置、关系
   - 新增事件、伏笔、道具、设定
   - 时间线推进与上一章衔接
4. 必要时直接更新 `00_memory/novel_state.md` 与相关 tracker；不要修改 `00_memory/novel_plan.md` 主线架构。
5. 写入门禁产物：
   - `04_editing/gate_artifacts/<chapter_id>/memory_update.md`

`<chapter_id>` 使用章节文件名去扩展名后的安全标识；应与 `chapter_gate_check.py` 的 `slugify(chapter_path.stem)` 保持一致。

## memory_update.md 格式

```markdown
# 记忆更新

- 章节：<章节文件名>
- 更新时间：<本地时间>
- 本章关键事实：
  - ...
- 角色状态变化：
  - ...
- 时间线推进：...
- 伏笔/设定变化：
  - ...
- 已更新文件：
  - ...
- 遗留风险：无 / ...
```

## 禁止事项

- 不得修改 `novel_plan.md` 的主线规划。
- 不得把分析说明写入章节正文。
- 不得跳过产物写入。
